# Captures d’écran — Météo intelligente

Déposez dans ce dossier les captures d’écran réelles de l’application **Météo intelligente Flutter**.

Noms de fichiers conseillés :
- `accueil.png` — écran météo principal
- `previsions.png` — prévisions sur cinq jours
- `recherche-ville.png` — recherche d’une ville
- `favoris.png` — écran des villes favorites
- `details-meteo.png` — détails météo

Après l’ajout des images, leurs noms pourront être utilisés dans le README principal avec des chemins relatifs, par exemple :

`![Écran météo principal](docs/images/accueil.png)`

Utilisez les noms exacts des fichiers lors de leur intégration au README.
