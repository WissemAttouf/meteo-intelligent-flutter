# 🌦️ Meteo Simple — Flutter Weather App

A weather application built with Flutter and Dart, designed to provide a simple and accessible weather experience.

## 📌 Overview

**Meteo Simple** is a Flutter mobile application project focused on weather information and a straightforward user experience.

This repository is part of my mobile development portfolio, demonstrating my work with Flutter, Dart, HTTP requests, and localization dependencies.

## ✨ Features

The following features should be listed as implemented only after they have been verified in the source code:

- Weather information display
- Weather data retrieval through HTTP requests
- French-language localization

## 🛠️ Tech Stack

- **Flutter** — Cross-platform application development
- **Dart** — Application programming language
- **HTTP** — HTTP request handling
- **Flutter Localizations** — Localization support
- **Intl** — Internationalization and locale-aware formatting

## 🚀 Getting Started

### Prerequisites

Install the following tools:

- Flutter SDK
- Dart SDK compatible with your Flutter installation
- Android Studio, VS Code, or another Flutter-compatible IDE

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/WissemAttouf/meteo-intelligent-flutter.git
   ```

2. Open the project directory:

   ```bash
   cd meteo-intelligent-flutter
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Check the development environment:

   ```bash
   flutter doctor
   ```

5. Run the application:

   ```bash
   flutter run
   ```

## 🧪 Testing

Run the available automated tests:

```bash
flutter test
```

Analyze the project:

```bash
flutter analyze
```
